# Birthday Site — 06.10.2026

A mobile-first, cinematic birthday microsite prototype.

## Replace placeholders

- `YOUR PHOTO 01` ... `YOUR PHOTO 06` → your photos.
- `heroPhoto` background → her/their favourite cinematic photo.
- Update the text in the letter and cards.
- Optional: add `music.mp3` to the project root. The music button is already wired up.
- The "Open when..." messages can be personalised.

## Suggested final stack

This prototype is intentionally dependency-free so it can be opened immediately.
For the final version, it can be migrated to React + Framer Motion and deployed on Vercel.

## Design principles

- cinematic rather than generic birthday-template
- scrapbook details without becoming cluttered
- mobile-first
- interactions reveal content instead of dumping everything at once
- real photos remain the visual focus
